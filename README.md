# Beneath the Surface

A local React + Vite informational website about tawilis, Taal Lake, and the fishing communities of Agoncillo, Batangas.

## Content and sources

The page covers tawilis, local culture, six dimensions of agri-tourism, conservation, and responsible visiting. Six expandable summaries distinguish background information from proposed improvements and offer practical visitor takeaways. An optional research panel contains the awareness ranking, including the tied Planning and Physical scores, the interpretation of all six scores as Unaware, and the absence of statistical testing between dimensions.

The six dimensions and research panel are paraphrased from the supplied Downloads document, Beneath-the-Surface-Six-Dimensions-of-Tawilis-Agri-Tourism-in-Agoncillo-Batanga (1).docx. Its title is credited in the research panel. The source document is not distributed with the site. Earlier background content was informed by G2-BSTM 4E.docx. Public conservation sources and photo credits remain linked in the footer.

Recommendations are presented as proposed improvements. Historical road completion figures and fish prices are not presented as current visitor information. Activities, schedules, prices, facilities, and restrictions require local confirmation. The site does not accept bookings or collect survey responses.

## Run locally

Run npm install if dependencies are missing, then npm run dev. Open the local URL printed by Vite.

## Production build

Run npm run build. Output is written to dist/. Photos are stored locally in public/assets/. Google Fonts are optional, with system font fallbacks.

## Interaction checks

Run npm test for navigation destinations, menu focus trapping and Escape, section focus after navigation, scroll-lock cleanup, switching to desktop, FAQ state, active navigation, and reduced motion. These checks do not replace visual browser review.
